# BunkBuddy

> **Know before you bunk.**

BunkBuddy is a mobile-first attendance planner for college students.

It uses the **timetable + academic calendar** to calculate attendance and lets students update it when real-life changes happen, such as cancelled classes, substitute professors, swaps, extra classes, or rescheduled classes.

## Features

* 📊 Automatic subject-wise & overall attendance
* 📅 Timetable + academic calendar
* 🔄 Handle real class changes
* 🎚️ Strict / Normal / Relaxed monitoring for each subject
* 🔮 Check how missing a class affects attendance
* 👥 Add friends with mutual approval
* 🤝 Create & join **Bunk Groups**
* 📈 See whether everyone in a Bunk Group can safely miss a class

## MVP

**Login → Select Semester/Class → Get Schedule → Track Attendance → Plan Bunks → Bunk With Friends**

The first version will be a **mobile-first web app** to test whether students actually find it useful before building a dedicated mobile app.

> **No extra features will be added to the scope without discussion and approval.**
